# 📚 শিক্ষাসাথী (Shikkha Sathi)

**বাংলায় AI স্টাডি ও স্কিল সহায়ক ওয়েবসাইট**

শিক্ষার্থীদের জন্য বানানো একটি ওয়েব অ্যাপ, যেখানে সহজ বাংলায় পড়া শেখা যায়, শেখার পরিকল্পনা বানানো যায়, আর খেলার ছলে প্রতিদিন নিয়ম করে অনুশীলন করা যায়। ইনস্টল করার দরকার নেই, ব্রাউজারেই চলে।

## ✨ ফিচারসমূহ

| ফিচার | কী করে |
|---|---|
| 🧑‍🏫 **AI টিউটর** | যেকোনো বিষয়ের প্রশ্নের উত্তর সহজ বাংলায় দেয় |
| 🗺️ **রোডম্যাপ জেনারেটর** | লক্ষ্য, স্তর ও সময় অনুযায়ী ধাপে ধাপে পরিকল্পনা বানায় |
| 📈 **প্রগ্রেস ট্র্যাকার** | শতাংশ, ধাপ, স্ট্রিক ও গত ৭ দিনের হিসাব দেখায় |
| 🎯 **কুইজ** | যেকোনো বিষয়ে ৫টি প্রশ্ন বানায়, উত্তরের ব্যাখ্যাসহ |
| 🃏 **ফ্ল্যাশকার্ড** | ভুল কার্ড বারবার আসে, জানা কার্ড বিরতি দিয়ে ফেরে (স্পেসড রিপিটিশন) |
| ⏱️ **ফোকাস টাইমার** | ১৫, ২৫ বা ৪৫ মিনিটের মনোযোগ সেশন |
| 🏅 **গেম সিস্টেম** | XP, লেভেল, ব্যাজ, দৈনিক লক্ষ্য, হার্ট ও শব্দ |
| 📚 **ফ্রি রিসোর্স** | বাছাই করা ফ্রি কোর্স ও টুলের লিংক |

এছাড়া আছে প্রতিদিনের অনুপ্রেরণার বাক্য, ডার্ক মোড এবং ফোন ও কম্পিউটার দুটোতেই চলার মতো রেসপন্সিভ ডিজাইন।

## 🚀 চালানোর নিয়ম

এটি একটিমাত্র HTML ফাইল। কোনো বিল্ড টুল বা ডিপেন্ডেন্সি লাগে না।

1. রিপোজিটরি ক্লোন করো অথবা `index.html` ডাউনলোড করো:
   ```bash
   git clone https://github.com/mahirahman0132-maker/shikkha-sathi.git
   ```
2. `index.html` ফাইলটি ব্রাউজারে খোলো।

## 🌐 GitHub Pages-এ হোস্ট করা

1. রিপোজিটরি **Public** রাখো।
2. **Settings → Pages**-এ যাও।
3. Branch হিসেবে `main` এবং ফোল্ডার `/ (root)` বেছে **Save** দাও।
4. কিছুক্ষণ পর সাইট পাওয়া যাবে এই ঠিকানায়:
   `https://তোমার-ইউজারনেম.github.io/shikkha-sathi`

## ⚠️ AI ফিচার নিয়ে জরুরি কথা

AI টিউটর, রোডম্যাপ জেনারেটর, কুইজ ও ফ্ল্যাশকার্ড বানানোর অংশ Claude প্ল্যাটফর্মের ভেতরে চলার জন্য লেখা। তাই নিজের GitHub Pages-এ বা ডাউনলোড করা ফাইলে এই অংশগুলো কাজ করবে না।

বাকি সবকিছু (ফোকাস টাইমার, XP, হার্ট, ব্যাজ, প্রগ্রেস, রিসোর্স লিস্ট এবং আগে বানানো ফ্ল্যাশকার্ড রিভিউ) স্বাভাবিকভাবে চলবে।

নিজের হোস্টিংয়ে AI অংশ চালাতে চাইলে `getSample()` ফাংশনের জায়গায় নিজের AI API কল বসাতে হবে। API কী কখনো সরাসরি ফ্রন্টএন্ড কোডে রেখো না, সার্ভার বা সার্ভারলেস ফাংশনের মাধ্যমে ব্যবহার করো।

## 💾 ডেটা কোথায় থাকে

XP, স্ট্রিক, রোডম্যাপ ও ফ্ল্যাশকার্ডের অগ্রগতি ব্যবহারকারীর নিজের ব্রাউজারের `localStorage`-এ জমা থাকে। কোনো সার্ভারে পাঠানো হয় না। ফলে এক ডিভাইসের অগ্রগতি অন্য ডিভাইসে দেখা যায় না।
